# 图标文件说明

## 需要的图标文件

本项目需要以下图标资源：

### 1. icon.ico (必需)
- **用途**: Windows可执行文件图标和系统托盘图标
- **格式**: ICO格式
- **尺寸**: 建议包含 16x16, 32x32, 48x48, 256x256
- **颜色**: 建议使用简单的圆形图标
  - 绿色圆点表示"运行中"
  - 红色圆点表示"已停止"

### 2. icon.png (可选)
- **用途**: Linux/macOS图标
- **格式**: PNG格式
- **尺寸**: 512x512

## 如何创建图标

### 方法一：在线工具
1. 访问 https://www.favicon-generator.org/
2. 上传PNG图片
3. 下载生成的ICO文件

### 方法二：使用GIMP
1. 打开GIMP
2. 创建新图像 (32x32像素)
3. 绘制图标
4. 导出为ICO格式

### 方法三：使用ImageMagick
```bash
convert icon.png -define icon:auto-resize=256,48,32,16 icon.ico
```

## 临时方案

在找到合适的图标之前，程序会使用系统默认图标。
要使用自定义图标，请将 `icon.ico` 文件放在此目录下。

## 图标设计建议

- 简洁明了，易于识别
- 使用与讯飞星辰相关的配色
- 适合小尺寸显示（托盘图标）
